# Casa do Bolo do Léo Doce e Mel

Site cinematográfico, cardápio, pedidos e acompanhamento.

## Deploy

Esta pasta é gerada por `py deploy_vercel.py` na raiz do projeto local.
Não edite arquivos desta pasta diretamente: edite a origem e gere de novo.

## API

`/api/index.py` atende todas as rotas `/api/*`.
Os pedidos ficam no Turso/libSQL. O catálogo é estático em `cloud_lib/catalog.json`.
